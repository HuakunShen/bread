# Journal: Homebrew tap token scope

- Timestamp: 2026-09-15 09:39 (Asia/Singapore)
- Core Decision/Topic: Keep the Homebrew tap token limited to the tap repository.
- Options Considered: Expand the token to read the bread repository; change the publisher to download the public bread.rb release asset without the token.
- Final Decision & Rationale: Use the public release URL. A token scoped only to HuakunShen/homebrew-tap is the least-privilege configuration, but the old script used gh release download and failed with HTTP 403 before it could write the tap.
- Key Changes Made: scripts/publish-homebrew-formula.sh now downloads bread.rb with curl and uses GH_TOKEN only for the tap contents API. A regression test exercises the tap-only token path.
- Future Considerations: Re-run the GitHub Homebrew workflow with v0.2.3 and keep the token repository selection limited to homebrew-tap.
