bread

Read the context you already know in one bounded, deterministic batch. Parallel file I/O, stable output order, line ranges, JSON, checksums, and cross-platform releases.

Install

go install github.com/HuakunShen/bread/cmd/bread@latest
curl -fsSL https://raw.githubusercontent.com/HuakunShen/bread/main/install.sh | bash
brew tap HuakunShen/tap && brew install bread
One turn

Batch independent files instead of paying one model round trip per file.

Safe bounds

Use inclusive line ranges and aggregate byte limits to keep context useful.

Any agent

Use the CLI from Codex, Claude Code, OpenCode, or a normal terminal.

The idea

unknown paths  → search first
one known file  → normal read
many known files → bread / parallel read
dependent next target → sequential read
