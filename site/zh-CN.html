Agent infrastructure · Go · MIT

bread

把已经知道的多个文件或代码行范围，在一次有界、可复现的结果中读取出来。并行文件 I/O、稳定输出顺序、JSON、校验和，以及跨平台 Release。

下载最新版本English

安装

go install github.com/HuakunShen/bread/cmd/bread@latest
curl -fsSL https://raw.githubusercontent.com/HuakunShen/bread/main/install.sh | bash
brew tap HuakunShen/tap && brew install bread
减少回合

把独立文件放进一次 batch，避免每个文件都触发一次模型往返。

有界读取

用行范围和总字节上限控制上下文，不把整个仓库倾倒给模型。

任意 Agent

Codex、Claude Code、OpenCode 或普通终端都可以调用。

原则

不知道路径   → 先搜索
知道一个文件 → 正常读取
知道多个文件 → bread / 并行读取
后一个目标依赖前一个结果 → 顺序读取
